Step-By-Step Guides for Teams That Count Stock.

Short, plain steps you can use this week. No software needed.

Bars and Restaurants

Run a Monday Count That Holds Up

Most variance starts as a bad count. Fix the count first.

Same shelf order every week. Nothing skipped, nothing counted twice.

  1. Count on the same day and time every week, before open.
  2. Freeze movement: no transfers or deliveries while counting.
  3. Count in shelf order, station by station, so nothing is skipped or doubled.
  4. Record partial bottles in tenths. Eyeball the same way every time.
  5. Count kegs by status: full, on tap, empty. Note when a keg was tapped.
  6. Have a second person recount your 10 most expensive items.
  7. Enter the count before leaving. Flag anything that looks odd.
  8. Lock the count so later edits are visible.

Read a Variance Report in 10 Minutes

A short routine for managers who open the report and freeze.

Premium Gin Y
−2.7
House Gin X
+3.0

Equal and opposite: often a premium pour rung in as house.

Spirit A
−34%
Spirit B
−34%
Mixer
−36%

Same percent together: often one batch logged at the wrong yield.

  1. Start with the net dollar total, then the top 5 items by dollars.
  2. Look for opposite pairs: one item short, a similar one over. That is often a wrong button.
  3. Look for groups: several items from one batch all off by the same percent. That is often a wrong recipe yield.
  4. Ignore count noise: under one bottle, or inside your own allowance.
  5. Read draft in kegs and percent, not bottles.
  6. Check the waste and comp log for the shortage items before anything else.
  7. Write down three things to verify this week. Stop there.
Bars and Restaurants

Cost a Cocktail in Five Steps

Know what a drink costs before you argue about its price.

Gin $1.80Juice, syrup, garnish $0.35Menu price $14.00

0% pour cost

  1. Pick the pour size, for example 45 ml.
  2. Cost per ml = bottle price divided by bottle size. A $30, 750 ml bottle is $0.04 per ml, so 45 ml costs $1.80.
  3. Add every other ingredient: juice, syrup, garnish. Say $0.35 together.
  4. Add them up: $1.80 + $0.35 = $2.15 per drink.
  5. Divide by the menu price before tax. $2.15 / $14 is about 15%. Compare it with your own target, not a rule of thumb.
Hotels

Close a Banquet Bar by Event

One event rung under the wrong code can hide in a whole week of counts.

Event bar usage
+18
Traced to one event
14

Fictional example. 18 bottles beyond event sales; 14 trace to one event rung under the wrong event code.

  1. Give every event its own code before the bar opens.
  2. Count the bar before and after each event, not only at week end.
  3. Record bottles opened and bottles returned to stock, with the event code.
  4. Compare each event’s usage with its own sales, not the weekly total.
  5. If one event is far off, check its code and its sales entry before anything else.
  6. Write down the event, the gap and the fix. Stop there.

Reconcile an In-Room Minibar Program

Match what was restocked with what was charged, floor by floor.

Restocked
40
Charged to rooms
34

Fictional example. 6 items restocked but never charged: a posting question, not a theft question.

  1. Count each floor or restock round on the same day and time.
  2. List what was restocked, by item and room.
  3. List what was charged to those rooms for the same period.
  4. Gap = restocked minus charged, after expiry and damaged items.
  5. Check the biggest gaps for a posting delay or a wrong item code first.
  6. Write down three rooms or items to verify. Stop there.
Home Services and Trades

Count Truck Stock Against Job Tickets

Parts leave the shelf faster than tickets record them. Count the gap.

Part A 3/4 in.
−30
Part B 3/4 in.
+28

Fictional example. Near-identical parts, opposite gaps: two part numbers for one fitting.

  1. Pick your 10 highest-cost parts. Start there, not with everything.
  2. Count each truck on the same day each week, before dispatch.
  3. Record counts per truck, not just for the shop.
  4. List parts used on job tickets for the same period.
  5. Expected = opening count + loaded − used on tickets. Compare with today’s count.
  6. Look for opposite pairs: one part short, a similar one over.
Home Services and Trades

Find Duplicate Part Numbers

Two numbers for one fitting look like a loss. They are a recording issue.

Part A
−30
Part B
+28

Fictional example. Roughly equal and opposite gaps are the signature of a duplicate.

  1. List shortages and overages side by side for the same period.
  2. Look for similar descriptions: same size, brand or fitting type.
  3. Check the supplier number against your own number for each.
  4. If they are the same item, map them to one number.
  5. Recount after the mapping and see what gap remains.
  6. Only the remaining gap needs a physical check.
Construction and Real Estate

Match Material Orders to Job Costs

If more was ordered than billed, find which job took it.

Ordered
220
Billed to jobs
180
One miscoded job
31 of 40

Fictional example. 220 sheets ordered, 180 billed; 31 of the 40 gap trace to one job coded to the wrong project.

  1. List orders by material for one period.
  2. List what was billed to each job for the same period.
  3. Gap = ordered minus billed, less returns and stock still on site.
  4. Group the gap by job code, not by supplier.
  5. Check the largest job first for a wrong project code.
  6. Check offcuts and waste against your own allowance.
  7. Write down three checks. Stop there.

Count Maintenance Stock Across Properties

The pattern across buildings matters more than any single shortage.

Property 1
−2
Property 2
−2
Property 3
−8

Fictional example. One building runs well above the others on the same item.

  1. Pick 15 common items: filters, bulbs, fittings, cleaning supplies.
  2. Count every property on the same day, with the same list.
  3. Separate the central store from site stock.
  4. Log every transfer between them.
  5. Compare issued stock with work orders for each property.
  6. Look for the property that stands out, then check that one first.
